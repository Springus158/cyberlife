# Official addons

Curated addons shipped with Cyber Life. Install one by copying its folder
into `~/.cyberlife/addons/` and enabling it in *Settings → Addons* (or ask
your agent to do it — `addons_reload` + `addons_set_enabled`).

Want yours here? See the "Submitting an official addon" checklist in
[CONTRIBUTING.md](../CONTRIBUTING.md). For a starting template, see
[`examples/addons/hello-world`](../examples/addons/hello-world).
